# Experiments and scores

- `initial_eda_summary.json`: previously verified EDA measurements from user's uploaded competition ZIP.
- `score_updates.csv`: append user-reported LB outcomes using `scripts/record_score.py`. First row is a context note of 0.547, NOT a verified model OOF score.
- `experiments.csv`: CODEx writes each trained model's actual CV metrics and resources.
- `baseline_metrics.json`, `baseline_oof.csv`, `baseline_fold_assignments.csv` are generated by executable classical baseline.
- All OOF files may contain labels and identifiers from competition data. Keep private.

Local P0 runs use `reports/p0_20261018_run*/` and matching `artifacts/` directories.
Each run saves full aggregate/per-fold metrics, private OOF/fold CSVs, diagnostics,
and a manifest with hashes, commands, dependencies and measured resources.
The top-level `baseline_metrics.json` remains the historical sandbox result.
Recursive git-ignore rules protect nested OOF and fold mappings; aggregate
reports remain local unless an authorized, rules-compliant release is requested.
